# Лендинг «Офисная мебель под ключ»

Одностраничный лендинг по ТЗ (`тз лендинг (автовосстановление) (2).docx`).
Чистый **HTML + CSS**, без JavaScript и без сборки — открывается двойным кликом по `index.html`.

## Структура

```
index.html          вся разметка страницы
css/style.css       стили (токены, компоненты, адаптив)
img/*.svg           изображения-заглушки (векторные сцены офиса, логотипы, карта)
```

## Интерактив без JavaScript

* **Мобильное меню** — скрытый `<input type="checkbox" id="nav-toggle">` + `label.burger`
  (селекторы `.nav-toggle:checked ~ .container .nav`).
* **Модальная форма** — псевдокласс `:target`: любая кнопка ведёт на `#lead`,
  крестик и подложка — на `#top`.
* Плавная прокрутка — `scroll-behavior: smooth`.

## Что нужно заменить перед публикацией

1. **Изображения.** Все файлы в `img/` — векторные заглушки. Замените на реальные фото:
   поменяйте `src` в `index.html` (например `img/zone-executive.svg` → `img/zone-executive.jpg`).
   Пропорции заданы в CSS через `aspect-ratio`, фото подрежется по `object-fit: cover`.
   * `zone-*.svg` — зоны офиса (4:3)
   * `project-*.svg` — проекты (16:10)
   * `chair.svg` — кресло для блока «Тест-драйв» (по ТЗ фото запрашивается у заказчика)
   * `client-*.svg` — логотипы клиентов (по ТЗ запрашиваются у заказчика)
   * `designers-scene.svg`, `hero.svg`, `map.svg`
2. **Название и логотип.** Сейчас нейтральная заглушка «ОФИСПРОЕКТ» —
   инлайновый SVG в шапке и подвале, плюс `<title>`, `favicon` и тексты.
3. **Контакты.** Телефон `+7 (495) 000-00-00`, почта `info@example.com`, адреса офиса и склада —
   заглушки, встречаются в шапке, подвале и блоке «Контакты».
4. **Карта.** `img/map.svg` — стилизованная заглушка. Для живой карты вставьте
   `<iframe>` Яндекс.Карт вместо `<img>` внутри `.contacts__map`.
5. **Формы.** У четырёх форм (`.form--row`, `.card-form`, форма в модалке) стоит `action="#"` —
   подключите обработчик (CRM, почта, Битрикс24 и т. п.) и добавьте страницу «Спасибо».
6. **Презентация.** Кнопки «Скачать презентацию» ведут на лид-форму (выдача после заявки).
   Если нужен прямой файл — замените `href="#lead"` на `href="presentation.pdf" download`.
7. **Политика конфиденциальности** — ссылки `href="#privacy"` ведут в подвал,
   замените на реальную страницу.

## Адаптив

Брейкпоинты: `1180px` (бургер-меню), `1080px`, `900px`, `720px`, `520px`.
Учтены `prefers-reduced-motion` и печать.

## Референсы из ТЗ

`b2b.mavikom.ru`, `lp.mavikom.ru`, `mir-kabinetov.com`, `flex-office.biz` —
использованы как ориентир по структуре и визуальному языку (тёмный текст,
бирюзовый и оранжевый акценты, скруглённые карточки, много воздуха).
Тексты и контакты — свои, чужой брендинг не используется.
